Wellness Watch Acne is a full-stack web application that combines a custom-trained machine learning model with an interactive acne tracking experience. Users can upload a skin image to receive an AI-generated acne classification and confidence score, while the built-in tracker allows them to log factors such as food intake, sleep, workout-to-shower timing, and skincare products. I built the project end-to-end, including the custom image dataset and MobileNetV2 classifier, Flask prediction API, and React frontend.

For educational and informational purposes only. Wellness Watch Acne is not a medical diagnosis tool, and its predictions should not be used as a substitute for professional medical advice, diagnosis, or treatment.

The Full App repository contains the React web application and Flask API, while the ML Classifier repository contains the machine learning model and training workflow.

Digital Marketplace

A Role-Based Clothing Marketplace with a Simulated Escrow Workflow

December 2024 · Full-Stack Development · Relational Database Design · Academic Collaboration

  • React 18
  • JavaScript
  • React Router
  • Axios
  • Node.js
  • Express.js
  • MySQL 8
  • SQL
  • REST API
  • MySQL Workbench

This project addressed trust in peer-to-peer clothing transactions by introducing a middleman workflow that holds buyer funds until an order is received before releasing payment to the seller. We first designed the system through an EER diagram, relational model, HIPO diagram, and data-flow diagram, then translated those designs into a MySQL-backed web application with separate buyer, seller, and middleman workflows for listings, purchases, order tracking, transaction management, and fund release.

This application is an educational prototype. Its payment and escrow features simulate a transaction workflow and do not process or transfer real money. For the complete development workflow, additional system diagrams, and full application walkthrough, view the linked User Manual.
